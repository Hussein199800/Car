# طاقتي ☀️

تطبيق أندرويد عربي لمراقبة منظومة الطاقة الشمسية، ويعمل بنفس حساب تطبيق **WatchPower**
(الإنفرترات المتصلة بوحدة واي فاي على منصة DessMonitor / ShineMonitor).

## المزايا
- **لوحة حية متحركة**: تدفق الطاقة بين الألواح والكهرباء الوطنية والبطارية والمنزل، وتتغير سرعة الحركة حسب القدرة.
- **البطارية**: نسبة الشحن على شكل حلقة، وتقدير المدة المتبقية للتفريغ أو للشحن الكامل.
- **السجل والرسوم**: القدرة ونسبة الشحن وجهد البطارية وجهد الكهرباء لأي يوم، مع الإنتاج والاستهلاك اليومي بالكيلوواط ساعة.
- **تنبيهات ذكية**: انخفاض البطارية، والحمل الزائد، وانقطاع الكهرباء وعودتها، واكتمال الشحن، وأعطال الإنفرتر.
- **إعدادات الإنفرتر**: قراءة الإعدادات وتعديلها (أولوية الخرج والشحن وغيرها) مع طلب تأكيد قبل كل تغيير.
- **وضع تجريبي** لاستكشاف التطبيق بدون حساب.

## تنزيل ملف APK
مع كل رفع للكود يبني GitHub Actions التطبيق تلقائياً:
**Actions ← «بناء تطبيق أندرويد» ← آخر تشغيل ← Artifacts ← `taqati-apk`**.

## التطوير
```bash
npm install
npm run serve      # تشغيل الواجهة في المتصفح على المنفذ 8080 (الوضع التجريبي)
npm run apk        # بناء ملف APK (يتطلب Android SDK و JDK 21)
```

البنية:
- `src/api.js` اتصال بخوادم WatchPower وتوقيع الطلبات
- `src/model.js` توحيد القراءات وترجمتها للعربية، والبيانات التجريبية
- `src/main.js` الواجهة: الرئيسية والسجل والتنبيهات والإعدادات
- `src/styles.css` التصميم

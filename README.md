# طاقتي ☀️

تطبيق أندرويد عربي لمراقبة منظومة الطاقة الشمسية، ويعمل بنفس حساب تطبيق **WatchPower**
(الإنفرترات المتصلة بوحدة واي فاي على منصة DessMonitor / ShineMonitor).

## المزايا
- **دقة البيانات أولاً**: يقرأ التطبيق وقت آخر قراءة. إذا تجاوز عمرها 15 دقيقة (قابلة للتعديل) يُعرض الرافع «غير متصل» مع وقت آخر قراءة، وتتوقف الحركة والحسابات بدل عرض قيم قديمة كأنها حيّة.
- **خمسة تبويبات فقط** (الرئيسية، التقارير، الحاسبة، التنبيهات، المزيد)، وفي كل منها بطاقات ملونة تفتح صفحات فرعية قصيرة.
- **الرئيسية**: مخطط متحرك لتدفق الطاقة، وحلقة البطارية، وصفحات تفصيلية للحمل والبطارية والألواح والكهرباء والإنفرتر.
- **التقارير**: يومية وأسبوعية وشهرية، ومقارنة الأداء مع الفترة السابقة، وتصدير CSV ومشاركته.
- **التنبيهات**: انقطاع الإنفرتر وعودته، وانقطاع الكهرباء، وانخفاض البطارية، والحمل الزائد، والأعطال. تعمل **حتى والتطبيق مغلق** (فحص كل 15 دقيقة تقريباً)، مع سجل للأعطال والانقطاعات. للتنبيهات هامش رجوع (البطارية +5%، الحمل −10%، الامتلاء 95%) حتى لا تتكرر الإشعارات مع تذبذب القراءة حول الحد.
- **الإنفرتر**: الحالة ومعلومات الجهاز والقيم المقنّنة والإعدادات الحالية في صفحة واحدة، وتعديل الإعدادات عن بُعد بعد التأكيد.
- **حاسبة الأحمال**: تحويل أمبير الكهرباء إلى واط وإلى أمبير البطارية (12/24/48 فولت)، وقائمة أجهزة البيت مع تيار الإقلاع والاستهلاك اليومي واقتراح الألواح وسعة البطارية على متوسط السحب الفعلي.
- **ربط الجهاز والحساب**: دليل إنشاء حساب وإعداد الواي فاي (Wi-Fi Config) والبلوتوث مع فتح تطبيقات WatchPower الرسمية.
- **التحديثات من داخل التطبيق**: يتحقق التطبيق من صفحة إصدارات المستودع على GitHub (تلقائياً كل 12 ساعة، أو يدوياً من «المزيد»)، فينزّل ملف APK ويتحقق قبل التثبيت أنه «طاقتي» نفسه، وأحدث، وموقّع بالمفتاح نفسه. عند الدمج في `main` ينشر GitHub Actions الإصدار الموقّع تلقائياً مع نص `release-notes.md`.
- **النسخة الاحتياطية**: ملف مشفّر (AES-256-GCM بمفتاح من رمز يختاره المستخدم عبر PBKDF2-SHA256، 310 ألف تكرار) يحفظ الحساب وكل الإعدادات، ويُستعاد من شاشة الدخول بعد إعادة التثبيت فيدخل مباشرة. لا يحتوي كلمة المرور نفسها بل بصمتها، ولا يُقبل منه إلا الإعدادات المعروفة ضمن حدودها.
- **بدون إنترنت**: تُحفظ آخر البيانات وقراءات اليوم على الهاتف وتُعرض مع وقت آخر تحديث.
- **النصائح**: نصائح مخصّصة مبنية على قراءات جهازك وإعداداته، ونصيحة اليوم، وأقسام لاستخدام الرافع وبطاريات الليثيوم والتوفير والسلامة وفهم الأرقام.
- **مناسب لكل الدول**: تسمية الجهاز (الإنفرتر/الرافع/العاكس) والكهرباء (الشبكة/الوطنية/العمومية/الحكومة) قابلة للاختيار، واكتشاف تلقائي لفرق التوقيت بين الخادم والهاتف، ودعم أنظمة 12 و24 و48 فولت وشبكات 110 و230 فولت.
- **الوضع النهاري والليلي** والتلقائي، وواجهة عربية بالكامل (RTL).

## النشر
- التطبيق يُوزَّع كملف APK موقّع. **مفتاح التوقيع لا يُرفع إلى المستودع أبداً** (`*.jks` و`keystore.properties` مستثناة).
- كل تحديث يجب أن يُوقَّع بالمفتاح نفسه وأن يزيد `versionCode` في `android/app/build.gradle`، وإلا لن يُثبَّت فوق النسخة السابقة.
- لإصدار جديد: غيّر رقم الإصدار في `package.json` و`src/main.js` و`android/app/build.gradle` (اختبار آلي يتأكد من تطابقها)، واكتب الجديد في `release-notes.md`، ثم ادمج في `main`؛ يُنشر الإصدار ويصل للمستخدمين تلقائياً.
- البناء التلقائي على GitHub: أضف السرّين `TAQATI_KEYSTORE_BASE64` و`TAQATI_KEYSTORE_PASSWORD` في
  **Settings ← Secrets and variables ← Actions**، فيبني GitHub نسخة موقّعة مع كل رفع
  (**Actions ← آخر تشغيل ← Artifacts ← `taqati-apk`**). بدون الأسرار تُبنى نسخة تجريبية غير صالحة للنشر.
- محلياً: ضع ملف `android/keystore.properties` (storeFile, storePassword, keyAlias, keyPassword) ثم شغّل `npm run release`.

## البنية التقنية
تطبيق Android مبني على **Capacitor 8**: الواجهة (HTML/CSS/JavaScript) تعمل داخل WebView، وطبقة **Kotlin** أصلية لما لا تستطيعه الواجهة:

| الطبقة | الملفات | الدور |
|---|---|---|
| الواجهة | `src/*.js`, `src/styles.css` | اللوحة والتقارير والتنبيهات والإعدادات، RTL، نهاري/ليلي، متجاوبة مع الهاتف واللوحي |
| الاتصال | `src/api.js` | التوقيع والطلبات لخوادم WatchPower |
| Kotlin | `android/app/src/main/java/com/taqati/solar/` | `SecureStore` تخزين مشفّر بـ Android Keystore · `MonitorWorker` مراقبة كل 15 دقيقة والتطبيق مغلق (WorkManager) · `WatchPowerClient` و`AlertEvaluator` نسخة أصلية من الاتصال وقرار التنبيه |

### آلية الاتصال
لا يوجد اتصال محلي بالإنفرتر: وحدة الواي فاي ترفع القراءات إلى خادم WatchPower السحابي (DessMonitor/ShineMonitor) كل بضع دقائق، والتطبيق يقرؤها من هناك عبر HTTPS:
1. الدخول `authSource` (أو `auth` لخادم ShineMonitor): التوقيع `sha1(salt + sha1(password) + action)` ويعيد `token` و`secret`.
2. بقية الطلبات توقَّع `sha1(salt + secret + token + action)`: `queryPlants` و`webQueryDeviceEs` (الأجهزة)، و`queryDeviceLastData` (آخر قراءة)، و`queryDeviceDataOneDayPaging` (سجل اليوم)، و`queryDeviceCtrlField`/`queryDeviceCtrlValue`/`ctrlDevice` (الإعدادات).
3. هذه الواجهة غير موثّقة رسمياً، ومأخوذة من سلوك التطبيق الرسمي ومشروع [ha-dessmonitor](https://github.com/andreas-glaser/ha-dessmonitor) مفتوح المصدر.
4. الخادم يعيد آخر قراءة محفوظة حتى لو كان الإنفرتر مطفأً، لذا يحكم التطبيق على الاتصال من **عمر القراءة**، مع اكتشاف تلقائي لفرق التوقيت بين الخادم والهاتف.

### الأمان (OWASP MASVS)
- **التخزين**: الجلسة وبصمة كلمة المرور مشفّرة بـ AES-256-GCM بمفتاح داخل Android Keystore، وكلمة المرور نفسها لا تُحفظ. النسخ الاحتياطي والنقل بين الأجهزة معطّلان.
- **الشبكة**: HTTPS فقط (`network_security_config`)، والثقة بشهادات النظام فقط.
- **المنصة**: سياسة أمان محتوى (CSP) تمنع أي سكربت أو اتصال خارجي، وتهريب كل النصوص القادمة من الخادم، ومشاركة الملفات من مجلد مؤقت فقط، وحذف صلاحية المنبّهات الدقيقة غير المستخدمة.
- **الخصوصية**: لا تحليلات ولا جهات خارجية. الاتصال بخوادم WatchPower فقط.

## الاختبارات
```bash
npm test               # اختبارات وحدة JavaScript (التوقيع، التحليل، الانقطاع، المصطلحات، الملخصات)
npm run test:e2e       # اختبارات الواجهة في Chromium مع خادم وهمي (تحتاج Playwright)
npm run test:android   # اختبارات وحدة Kotlin (تطابق التوقيع مع JavaScript، قرار التنبيه)
```

## التطوير
```bash
npm install
npm run serve      # تشغيل الواجهة في المتصفح على المنفذ 8080 (الوضع التجريبي)
npm run apk        # نسخة تجريبية (debug)
npm run release    # نسخة النشر الموقّعة (تحتاج مفتاح التوقيع)
```

البنية:
- `src/api.js` الاتصال بخوادم WatchPower وتوقيع الطلبات
- `src/model.js` توحيد القراءات وكشف القراءة القديمة (الرافع غير متصل)
- `src/i18n.js` ترجمة أسماء الحقول والقيم والوحدات إلى العربية
- `src/data.js` التخزين المحلي وملخصات الأيام والتصدير
- `src/demo.js` بيانات الوضع التجريبي
- `src/tips.js` محتوى النصائح والنصائح المخصّصة
- `src/terms.js` تحويل المصطلحات حسب اختيار المستخدم
- `src/native.js` الجسر إلى طبقة Kotlin (التخزين المشفّر والمراقبة في الخلفية)
- `src/main.js` الواجهة والتبويبات والصفحات الفرعية
- `src/styles.css` التصميم (نهاري وليلي)

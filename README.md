# طاقتي ☀️

تطبيق أندرويد عربي لمراقبة منظومة الطاقة الشمسية، ويعمل بنفس حساب تطبيق **WatchPower**
(الإنفرترات المتصلة بوحدة واي فاي على منصة DessMonitor / ShineMonitor).

## المزايا
- **دقة البيانات أولاً**: يقرأ التطبيق وقت آخر قراءة. إذا تجاوز عمرها 15 دقيقة (قابلة للتعديل) يُعرض الرافع «غير متصل» مع وقت آخر قراءة، وتتوقف الحركة والحسابات بدل عرض قيم قديمة كأنها حيّة.
- **خمسة تبويبات رئيسية** (الرئيسية، التقارير، التنبيهات، الرافع، المزيد)، وفي كل منها بطاقات ملونة تفتح صفحات فرعية قصيرة.
- **الرئيسية**: مخطط متحرك لتدفق الطاقة، وحلقة البطارية، وصفحات تفصيلية للحمل والبطارية والألواح والكهرباء الوطنية.
- **التقارير**: يومية وأسبوعية وشهرية، ومقارنة الأداء مع الفترة السابقة، وتصدير CSV ومشاركته.
- **التنبيهات**: انقطاع الرافع وعودته، وانقطاع الكهرباء، وانخفاض البطارية، والحمل الزائد، وأعطال الإنفرتر، مع سجل مستقل للأعطال والانقطاعات.
- **الرافع**: الحالة التشغيلية، ومعلومات الجهاز، والقيم المقنّنة، والإعدادات الحالية، وتعديل الإعدادات عن بُعد بعد التأكيد.
- **بدون إنترنت**: تُحفظ آخر البيانات وقراءات اليوم على الهاتف وتُعرض مع وقت آخر تحديث.
- **الوضع النهاري والليلي** والتلقائي، وواجهة عربية بالكامل (RTL).

تطوير: **حسين محمد علي الطويل**

## تنزيل ملف APK
مع كل رفع للكود يبني GitHub Actions التطبيق تلقائياً:
**Actions ← «بناء تطبيق أندرويد» ← آخر تشغيل ← Artifacts ← `taqati-apk`**.

## التطوير
```bash
npm install
npm run serve      # تشغيل الواجهة في المتصفح على المنفذ 8080 (الوضع التجريبي)
npm run apk        # بناء ملف APK (يتطلب Android SDK و JDK 21)
```

البنية:
- `src/api.js` الاتصال بخوادم WatchPower وتوقيع الطلبات
- `src/model.js` توحيد القراءات وكشف القراءة القديمة (الرافع غير متصل)
- `src/i18n.js` ترجمة أسماء الحقول والقيم والوحدات إلى العربية
- `src/data.js` التخزين المحلي وملخصات الأيام والتصدير
- `src/demo.js` بيانات الوضع التجريبي
- `src/main.js` الواجهة والتبويبات والصفحات الفرعية
- `src/styles.css` التصميم (نهاري وليلي)

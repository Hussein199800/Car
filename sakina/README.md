# سكينة 🌙 رفيقك الروحي اليومي

تطبيق أذكار عربي بالكامل (RTL)، خفيف ويعمل **بدون إنترنت**، لأندرويد ٨ فما فوق وللمتصفح.

## التبويبات
1. **الرئيسية**: سماء تتغيّر ألوانها مع وقت اليوم، والتاريخ الهجري والميلادي، ومواقيت الصلاة مع عدّ تنازلي، و«بماذا يشعر قلبك الآن؟» (٨ حالات، لكل حالة آية ودعاء مأثور ورسالة سكينة)، وبطاقات: وردك الآن، وآية اليوم، وحديث اليوم، والمسبحة، واسم اليوم، وأيام الالتزام.
2. **الأذكار**: الصباح والمساء، وبعد الصلاة، والنوم، والاستيقاظ، والمنزل، والخلاء، والوضوء، والأذان، والمسجد، والطعام، والسفر، والأدعية القرآنية والنبوية، والرقية الشرعية، والمفضلة، وأذكاري الخاصة. يعمل البحث بدون تشكيل.
   - **وضع التركيز**: بطاقة واحدة مع حلقة تقدّم. النقر يعدّ، مع اهتزاز ونقرة صوتية، والانتقال تلقائي عند اكتمال العدد، والسحب يمين ويسار للتنقل.
   - **وضع القائمة**، مع أدوات: تكبير الخط وتصغيره، وإظهار التشكيل أو إخفاؤه، وتصفير العداد، ونسخ، ومشاركة نصاً أو صورة، ومفضلة.
3. **المسبحة**: ٨ تسبيحات مع فضل كل منها، وهدف ٣٣ أو ١٠٠ أو ١٠٠٠ أو مفتوح، ووضع التنفس التسبيحي، وإحصائيات يومية وكلية.
4. **مفكرتي**: أيام الالتزام المتتالية، وجدول الأسبوع، وصلوات اليوم، والواحة الروحية (نخلة لكل يوم تتم فيه أذكار الصباح والمساء)، وخط زمني للمناسبات الإسلامية القادمة، وأسماء الله الحسنى الـ٩٩ مع المعنى وكيف تدعو بكل اسم.
5. **الإعدادات**: ٤ ثيمات، وإعدادات القراءة، والموقع (GPS أو ٧٠ مدينة مدمجة)، و١٥ طريقة لحساب المواقيت، وبوصلة القبلة، وتنبيهات الأذكار والصلاة والجمعة، وتصدير البيانات واستيرادها ومسحها، وصفحة «حول التطبيق».

## البنية التقنية
- واجهة HTML/CSS/JavaScript بلا إطار عمل، تُجمَّع بـ esbuild بصيغة تعمل على WebView أندرويد ٨.
- **Capacitor 8** لأندرويد، مع الإضافات: التنبيهات المحلية، والاهتزاز، والموقع، والمشاركة، والملفات، وشريط الحالة.
- المواقيت تُحسب فلكياً على الجهاز (`src/prayer.js`)، وتُختبر مقابل مكتبة `adhan` المرجعية بفارق لا يتجاوز دقيقتين.
- التاريخ الهجري بتقويم أم القرى عبر `Intl`، مع بديل حسابي، وتعديل يدوي بين −٢ و+٢ يوم.
- كل البيانات في `localStorage` على الجهاز، دون أي اتصال خارجي.
- الخطوط (IBM Plex Sans Arabic وAmiri) مدمجة داخل التطبيق.

## الأوامر
```bash
npm install
npm test            # اختبارات الوحدة
npm run test:e2e    # اختبار الواجهة في Chromium
npm run serve       # تشغيل نسخة الويب على http://localhost:8090
npm run apk         # بناء APK محلياً (يتطلب Android SDK)
```

## بناء APK على GitHub
مع كل رفع يغيّر مجلد `sakina/` يبني GitHub التطبيق تلقائياً. تجده في **Actions ← «بناء تطبيق سكينة» ← Artifacts ← `sakina-apk`**.

لنسخة موقّعة صالحة للنشر، أضف السرّين `SAKINA_KEYSTORE_BASE64` و`SAKINA_KEYSTORE_PASSWORD` في إعدادات المستودع. مفتاح التوقيع لا يُرفع إلى المستودع أبداً.
